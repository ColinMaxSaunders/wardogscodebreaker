Correct-code stats

Every code a group marks Code correct is saved here, with no names attached. The tests below compare those codes against the simplest way a game could pick them: each digit chosen independently from 0–9. Anything that consistently strays from that points to how the developers actually built it.

Download CSV

Which codes to trust: codes found by guessing are slightly skewed, because the app tries non-repeating codes first and groups that give up never record a code. Codes your team fully revealed by capturing every tower have no such skew. To log one, enter every digit as known, then click Code correct.

Repeated digits

Do codes like 664 or 3133 ever happen? If digits never repeat, the game is probably drawing digits without replacement, and the app's non-repeating-first order is the best possible strategy.

How often each digit appears

If digits are fair, each of 0–9 shows up about 10% of the time. A missing 0, or a digit that shows up far too often, means the generator isn't fair.
